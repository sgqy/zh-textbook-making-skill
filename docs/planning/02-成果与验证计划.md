# 教材技能集合的目标成果与验证计划

本计划面向中文讲解教材的多 skill 集合。当前完成的是研究与规划草稿；正式技能、完整样章、媒体成品和行为评估均未完成。覆盖范围与进度按品类分别记录，不能以编程样章通过推断其他领域同样可用。

2026 年 11 月 19 日修订：补入程序教材实验环境的必备成果与验证情境，回应 musl 大纲试用后提出的交付要求。原有阶段状态描述历史计划；当前实现与实测结果以[验证记录](../verification.md)为准。

## 目标成果包

| 成果 | 计划内容 | 完成依据 |
|---|---|---|
| 技能集合 | 研究、策划、写作、练习、审校、排版、维护 7 个候选入口 | 单独可用，组合时交接清楚，不无故启动全流程 |
| 共用方法 | 材料分析、读者与目标、解释、反馈、审校、维护 | 规则有用途与边界，来源和本项目建议可区分 |
| 品类资料 | 编程、工程、数学、外语、视觉艺术、音乐、自然科学、人文 8 份候选模块 | 各自有案例、任务、评价和媒体差异；未研究部分标明 |
| 原创教学单元 | 逐步覆盖前五大方向；艺术分别试视觉与音乐 | 教学内容、活动、反馈完整，能检查该类独有问题 |
| 程序教材实验环境 | 平台与版本、搭建说明、配套文件、最小自检、章节实验与必要的重置方法 | 大纲有环境方案和待验项；成稿有可用材料、环境自检与实验运行记录；缺项不得标为完成 |
| 编排案例 | 从收集材料到选品类、删选内容和组织单元 | 可追溯选择理由，包含跨领域和目标变化情境 |
| 样张与媒体 | 根据实际单元制作所需格式和资产 | 真实渲染、播放或操作检查；缺失内容不宣称完成 |
| 评估与使用说明 | 任务、观察标准、结果和限制，入口与组合示例 | 能发现分类失误、模板误用和虚报验证 |

全部说明用中文，必要外语材料、术语、代码与符号按[语言约定](01-技能集合设计.md#讲解语言与范围)处理。研究案例不直接充当原创样章，也不将他人教材素材默认打包分发。

## 阶段与退出条件

| 阶段 | 交付 | 退出条件 | 当前状态 |
|---|---|---|---|
| A 研究与分类设计 | 分品类案例、材料分析流程、集合边界、编排试稿 | 能说明选品类、选结构与评价证据的理由，缺口明确 | 已有跨品类草稿；正文比较和中文样本仍需补充 |
| B 最小可用组合 | research、plan、write、review；编程完整单元 | 材料到修订可追溯；分类短任务不过度套用编程规则 | 未开始 |
| C 核心品类试用 | 工程、数学、外语、视觉艺术和音乐小单元；练习及排版入口 | 各类活动与反馈匹配；必要媒体和输出实际检查 | 未开始，按单元推进 |
| D 更广主题与维护 | 自然科学、人文扩展单元；维护入口和受控变更案例 | 不混淆数据、证明与解释；能定位受影响材料并重验 | 未开始 |
| E 真实使用修订 | 目标读者或教师试用、观察和修订记录 | 修订有真实依据，保留未解决问题 | 未安排真实参与者 |

阶段用于管理成熟度，不增加额外审批流程。若某单元缺必需媒体或专业核验，可交付标明状态的部分成果；该类验证保持未完成，其他独立任务继续。

## 原创验证单元候选

| 单元 | 主要检验目标 | 必需产出与关键检查 |
|---|---|---|
| 列表修改与共享引用 | 编程中的状态解释与图文代码一致 | 可复现实验环境及自检、可运行例子、状态图、预测及修改题 |
| 静力学中的对象分离 | 工程建模不被公式代替 | 明确模型、受力图、单位、求解、改变条件后的判断 |
| 否定全称命题与反例 | 数学的量词与证明义务 | 对照命题、例与非例、反例任务、逻辑检查 |
| 用日语确认预约时间 | 中文讲解与目标语言交际并存 | 对话和音频、信息差、澄清任务、可接受表达与反馈 |
| 背景变化与色彩感知 | 视觉材料是学习对象 | 可比较图样或实物安排、操作记录、观察与修改任务 |
| 节奏读谱与听辨 | 谱例、声音与表现目标对应 | 谱例、核对音频、听辨及节奏产出任务 |
| 根据数据解释一个生物现象 | 证据与模型的边界 | 数据来源、图表、竞争解释、结论限制 |
| 比较两份事件记录 | 人文解释与材料证据 | 可核查史料或明确标记的虚构练习材料、语境与论证 |

前三类不依赖外部人参与即可做部分专业检查；后五类可能需要媒体或真实表现才能完成相应验证。所有单元仍需试读，静态审查不能替代学习观察。上表是验证选题，不是规定未来教材必须包含的内容。

当前[品类编排试稿](04-品类编排试稿.md)只有结构示例，尚非完整教学单元。

## 计划中的行为评估

以下任务尚未执行。每项同时准备合格材料和缺陷材料，以观察误报和漏报；预期观察点留给评估者，不直接提示给待测 skill。

| 编号 | 情境 | 预期观察点 |
|---|---|---|
| T1 | 收到文章、讲义、视频脚本与课本摘录的混合材料 | 分清内容依据、教法参考和媒体资产；记录已读范围 |
| T2 | 材料很多，但读者和目标只支持入门单元 | 选择、删减并记录理由，不按资料长度决定篇幅 |
| T3 | 相同声音材料，分别要求信号编程、物理解释、音乐听辨 | 随学习产出选择主品类与证据，不按题材关键词路由 |
| T4 | 工程例题缺单位或图中坐标，最终数值碰巧正确 | 定位模型、图文或量纲问题，不只比较答案 |
| T5 | 数学材料用几个算例宣称证明普遍命题 | 指出证明缺口，给理由或适当反例 |
| T6 | 交际教材只有语法填空，并把所有日语换成中文 | 保留中文说明和目标语言活动，重新对齐目标 |
| T7 | 听力材料缺音频，或首屏已显示全部核对文本 | 区分脚本与可用听力单元，调整答案与转写时机 |
| T8 | 创作题只接受一张范作，反馈全是审美形容词 | 明确约束、意图与观察依据，接受合理多解 |
| T9 | 乐理材料有谱无声，却声称完成听辨训练 | 识别媒体与目标缺口，不把读谱当听辨验证 |
| T10 | 科学活动把构造数据称为实测、把相关当因果 | 标明数据身份，限制结论，避免编造实验记录 |
| T11 | 人文练习把单一材料中的观点当成事实 | 要求来源、语境和论证，区分事实与解释 |
| T12 | 课堂探究材料直接改为完全自学 | 补反馈路径、提示和自检条件，不只删掉“教师” |
| T13 | 用户只改一段或审一章 | 保持范围，不默认建整书目录或成套文件 |
| T14 | 环境不可运行、音频无法播放或样张未渲染 | 写明已做与未做，不捏造通过记录 |
| T15 | 仅凭颜色区分流程，与以颜色为对象的艺术任务 | 针对不同目标处理，避免一刀切转灰度 |
| T16 | 某术语、数据或媒体资产改变 | 找到受影响的正文、题目、答案和媒体，按需重验 |
| T17 | 程序教材只要求大纲，已有平台名称但缺少环境材料 | 补环境方案、材料计划和最小自检，关联章节实验；不擅自搭建或虚报运行 |

正式实现时还要检查 skill 的触发描述、参考资料可发现性和独立使用。无需为每条文体偏好编写机械测试；先验证能暴露实质错误的任务。

## 比较与真实试用

用相同请求和原始材料比较有无专用 skill 的产出。先确定观察项，再阅读结果；尽量减少评估者对版本来源的了解。记录分类、专业错误、先修缺口、任务匹配、反馈、媒体缺失、范围遵守及虚报检查等问题，不用单一总分掩盖差异。

真实读者试用先检查必要先修，再观察其完成未见过的任务。工程观察建模和解释，数学观察论证，外语观察交流，艺术观察作品与修改过程。记录受阻位置和提示使用，而非只收集“喜欢这本书”的意见。条件允许时再增加延后任务。

教师试教可参考 Carpentries 的试用与反馈方式；它不是本项目强制采用的认证流程。[Lesson Pilot Workshops](https://docs.carpentries.org/resources/curriculum/lesson-pilots.html)。

小规模试用用于找问题，没有足够比较条件时不宣称提高学习效果。若某项规则没有带来可解释的改进，应修改或删除，不为维护既定拆分继续扩充指令。

## 工具与格式

先复用工具完成一个真实单元，再决定是否自动化。适合优先自动检查的内容包括链接、编号、资产对应、指定环境的代码例子和输出清单。专业推理、活动适配和艺术反馈仍需单独审查。

具体排版引擎尚未选择。中文纸书先验证 PDF；可运行教程验证网页或 Notebook；外语和音乐要验证声音，视觉艺术要检查展示条件。格式转换应记录哪些活动保留、哪些需要外部资源、哪些目标发生变化。

本轮交付限于扩展研究、集合设计、分类流程和编排试稿。下一步是从阶段 B 开始实现四个入口，并逐类检验，而非直接宣布通用教材技能集合已经完成。
