# 材料收集之后，如何选品类并编排教程

本流程是教材集合的关键交接：研究入口提供材料和分析，策划入口据此选定当前主品类、子类型和教学结构。它适用于新教材或重新规划；局部改稿可直接沿用已明确的决定。

## 1. 先收集，暂不按目录填空

从已知主题、读者和用途出发收集材料。初始主题可以较宽，资料标签暂时保留候选，不在读材料前把全部内容锁进某种章节模板。

分清三种用途：

- **内容依据**：支撑要教的事实、原理、方法、论证或作品背景。
- **教法案例**：研究其他教材如何解释、安排活动和反馈。
- **教学资产**：可能用于成品的代码、图像、数据、音频、谱例、文本或实物说明。

同一来源可以承担多个用途，但需要分别核对。例如一部好评教材可作为编排参考，不因此自动成为所有专业结论的可靠依据；公开可读的作品也不自动允许复制进成果。

材料清单至少记录标题或标识、作者或机构、版本或日期、访问位置、实际阅读范围、用途和限制。视频只读了脚本就写“脚本”；只看到目录就不记录为已分析完整章节。来源的年代、口碑、权威性和对本项目的适配分别判断。

## 2. 将材料转成内容与任务分析

抽取每份材料能够支持的概念、操作、例子、活动和评价方式，合并重复内容，标出先修关系与冲突。先形成候选内容，不急于排章。

| 分析项 | 要回答的问题 |
|---|---|
| 学习内容 | 这里讲的对象和方法是什么？含哪些关键条件？ |
| 读者负担 | 假定会哪些概念、语言、工具或操作？ |
| 可用例证 | 哪个例子揭示机制，哪个只是展示结果？ |
| 活动与证据 | 学习者要产出什么？怎样判断完成？ |
| 使用条件 | 自学、教师、同伴、设备或媒体需要哪些支持？ |
| 缺口与冲突 | 哪个目标缺依据？差异来自版本、约定还是实质分歧？ |

冲突先查适用条件与原始语境，不能按来源数量投票。无法解决时保留争议，缩小结论或补充资料。材料少但足以完成小目标时可以开始；材料多却缺核心活动条件时，不应以数量宣告研究充分。

收集可以在“拟定目标已有可定位依据，关键先修和未解决缺口已知”时暂告一段落。后续策划或试稿暴露缺项再定向补充，不要求穷尽某学科的全部教材。

## 3. 在分析阶段选定具体品类

按以下问题依次判断，不只根据标题中的学科词：

1. 读者最终要解释、计算、证明、制造、测量、交流、创作、表现还是解释材料？可以有多个目标，但要确定本单元重点。
2. 哪类专业方法负责判定这些产出？该单元因此属于哪个主品类和子类型？
3. 是否需要辅助品类，例如工程中的数学、音乐中的物理、艺术中的编程？辅助内容提供支撑，不自动变成平行主线。
4. 现有材料、先修和支持条件允许采用什么编排？还缺哪些东西才能完成目标？

用户已经明确品类时，不擅自改换。材料和目标冲突时说明影响，先做能完成的分析；只有选择会实质改变目标或交付且无法从上下文判断，才提出聚焦问题。明确的中文讲解约束不重复询问。

### 品类决定记录

| 字段 | 需要写清楚的内容 |
|---|---|
| 主品类与子类型 | 例如“外语 / 生活交际”，而非只有“语言” |
| 辅助品类 | 具体支持什么任务，没有则省略 |
| 目标读者与条件 | 先修、自学或课堂、反馈、设备、时间范围 |
| 学习产出 | 读者应完成的可观察任务 |
| 判断证据 | 哪种回答、操作、作品或表现可以支持目标达成 |
| 材料依据 | 哪些已读来源支持内容，哪些只作教法参考 |
| 编排选择 | 线性学习、问题、实验、项目、探究、查补等及理由 |
| 媒体要求 | 哪些为必要资产，缺失会影响哪个目标 |
| 内容取舍 | 纳入、延后、删去和待补的项目及理由 |
| 状态 | 当前决定或有条件的暂定；哪些新信息会改变它 |

记录可直接写在任务书中，不强制建立新文件。不要用一个不透明的“匹配分数”代替选择理由。

## 4. 选定之后再编排

先安排完成目标所需的先修和核心活动，再决定解释、示范、练习、反馈和回顾的位置。每个单元至少能说明它帮助读者做什么、依赖什么以及怎样得到反馈；不强求同样的标题序列。

书级决定描述总体用途，章级可以细化子类型。例如工程书中的数学工具章可以采用证明或计算结构，但要说明它如何服务后续工程任务。主题跨领域时以单元目标划分，不把所有学科模块都加载一遍。

目录不能只是资料目录的重排。某段材料若只对进阶读者有用，可以移入拓展；某种媒介缺失时，要么补足，要么明确缩小教学目标，不能静默删除活动却保留原来的能力承诺。

## 5. 一个填好的选择记录

以下是原创模拟情境，用于说明流程，不是本轮实际收集过的项目材料。

**输入材料**：预约对话脚本、时间表达清单、音频、常见误解记录。读者会基本问候和数字，希望独立处理简单预约；教材以中文讲解。

**分析**：时间表达支持理解，脚本和音频支持听读；现有活动只有复述，尚不能检验是否能确认时间或请求澄清。音频质量和语境自然度仍需核验。

**品类决定**：主品类为外语，子类型为生活交际；词汇和语法查补作为辅助。学习产出是听到预约信息后确认日期与时间，并在不确定时提出澄清。证据是对变化信息作出合适回应，表达不必与范例逐字一致。

**取舍与编排**：先给场景和任务，再听取关键信息，讲解必要表达，进行有信息差的回应，最后更换时间再做一次。完整转写用于核对，放在适当位置；大段与任务无关的语法分类移到拓展。

**仍待补**：核验音频与脚本、可接受表达及反馈条件；没有实际播放或对话表现，不宣布单元验证完成。

## 6. 同一题材的不同决定

| 材料主题 | 用户要学会什么 | 主品类与子类型 | 编排和证据 |
|---|---|---|---|
| 声音 | 写程序生成和分析信号 | 编程 / 实现与实验 | 输入、表示、实现、测试；检查程序和结果 |
| 声音 | 解释振动与频率关系 | 自然科学 / 模型与观察 | 现象、测量或数据、模型、解释；检查证据与结论 |
| 声音 | 听辨节奏并再现 | 音乐 / 听觉与表现 | 听、比较、练习、表现、反馈；检查声音和实际产出 |
| 色彩 | 分析成像数据 | 编程或工程，视具体目标决定 | 数据、模型、实现或测量；说明误差与条件 |
| 色彩 | 制作有特定视觉效果的构图 | 视觉艺术 / 感知与制作 | 观察、控制变量、制作、比较、修改 |

如果目标后来变化，重新检查分类、活动、媒体和评价，不只替换标题。更详细的单元草稿见[品类编排试稿](04-品类编排试稿.md)。
