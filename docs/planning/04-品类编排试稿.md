# 品类编排试稿：把方法落到具体单元

下列均为原创的单元结构草稿，用来检验技能设计。它们不是从案例教材改写的完整章节，也尚未执行专业测试、制作完整媒体或开展试读。步骤数量仅服务各例，不构成统一章法。

## P：列表修改与共享引用

**品类与目标。** 编程 / 机制理解。读者会变量、条件、循环和函数；希望预测两个名称涉及同一可变对象时的状态变化。实现时先固定具体语言、版本和语义，避免把某一种对象模型说成所有语言都成立。

**编排。** 给一个可预测的小程序 → 先写预测 → 展示执行结果及状态图 → 解释名称、对象和修改的关系 → 改变复制或共享条件 → 独立预测并说明理由。

**反馈。** 不仅展示输出，还指出预测在哪一步偏离实际状态。迁移题改变嵌套结构或调用位置时，必须检查所选语言的真实语义，不能机械沿用浅层例子的答案。

**所需材料。** 可运行源码、对应输出、状态图及答案。本草稿未指定语言和提供源码，所以没有代码验证结果。

## E：静力学中的对象分离

**品类与目标。** 工程 / 模型分析。读者会向量基础；目标是从简化情境中选取研究对象，识别作用在该对象上的外力，构造可用于求解的模型。

**编排。** 说明对象、载荷和理想化条件 → 对比整体图与分离后的受力图 → 解释约束如何进入模型 → 列式与求解 → 检查单位、方向和数量级 → 更换研究对象或约束后重画图。

**活动草稿。** 提供两张候选受力图，其中一张遗漏一个已说明的外部作用。要求指出缺项、说明依据，再讨论这会如何影响方程。反馈首先检查对象边界和外力来源，随后才检查代数。

**边界。** 本单元属于建模入门，不承诺实验操作能力或真实结构设计能力。后续必须补正式图、条件、计算和独立核验。

## M：否定全称命题与寻找反例

**品类与目标。** 数学 / 逻辑与证明入门。读者会整数与基本不等式；目标是区分“不是所有对象都满足”与“所有对象都不满足”，并用有效反例否定全称命题。

**编排。** 用简单陈述辨认范围和条件 → 对照全称命题及其否定 → 检查候选反例是否属于允许范围 → 独立构造反例 → 修改命题条件并讨论新的证明义务。

**微型任务。** 判断命题“对每个整数 n，都有 n² > n”。写出否定，并给反例。

**反馈草稿。** 否定是“存在整数 n，使 n² ≤ n”；n = 0 或 n = 1 都是反例。只举 n = 2 验证原式成立，不能证明全称命题。这个答案只处理当前命题，不证明任何修改后的新命题。

**版式与检查。** 命题、论域和否定相邻；区分找反例的尝试与最终论证。需要审查量词、逻辑符号和练习条件；程序枚举即使使用，也只能作辅助观察。

## L：用日语确认预约时间

**品类与目标。** 外语 / 交际。读者会基本数字与问候；目标是确认预约时间，在没听清时请求重复。说明和反馈用中文，输入与回应保留日语。

**编排。** 用中文说明预约场景与需要确认的信息 → 听对话并记录 → 讲解必要的确认与澄清表达 → 根据不同角色持有的信息进行回应 → 更换日期或时间再交流 → 核对与回顾。

**表达草稿。** “火曜日の三時ですね。”可作为确认信息的例子；“もう一度お願いします。”可用于请求重复。完整材料还需要合适的上下文、音频与表达审查，不能以两句范例代替单元。

**反馈。** 检查是否确认正确信息、是否在需要时澄清、对方能否理解以及表达是否符合场景。允许多种合适表达。单纯背出范句不作为完成陌生预约任务的证据。

**媒体与范围。** 尚未制作音频或观察对话表现。核对转写可延后呈现，具体位置由练习目标决定；阅读辅助型练习也可以先给文本，不强制所有活动先隐藏转写。

## A：背景变化与色彩感知

**品类与目标。** 视觉艺术 / 感知与制作。目标是在控制形状和大小等条件时比较背景变化，并说明观察与修改依据。

**编排。** 准备中间色块相同、背景不同的两幅图 → 先描述所见 → 核对实际色值或实物材料 → 调整一种条件并记录 → 制作变体 → 比较意图与观察结果。

**活动草稿。** 让读者保留中间色块，选择两种背景，记录效果和显示条件，再尝试让差异更明显或更弱。允许观察不到预期差异，接着检查材料、尺寸、环境及观察方式，不预填统一感受。

**反馈。** 检查比较是否控制了条件、记录是否清楚、修改是否对应意图。不能只按与范图是否一致判分，也不能将主观描述包装成未经测量的实验结论。

**媒体与范围。** 尚无正式图样和实际展示检查。灰度版不能直接维持同一个色彩任务；若改成明度活动，应重新写目标。

## A-M：节奏的读谱与听辨

**品类与目标。** 音乐 / 理论与听觉。将“能读出时值关系”和“能听出节奏差异”分成两个目标，避免以文字知识代替听觉能力。

**编排。** 在固定拍速下听两个短例 → 比较相同拍数中的细分 → 用谱例对应声音 → 按提示再现 → 脱离谱例进行新的听辨 → 核对并练习。

**材料草稿。** 可以比较 2/4 拍中由两个四分音符或四个八分音符填满的一小节，保持拍速一致。正式内容需要谱例、准确音频和明确的起拍提示；不能只给两个文件名。

**反馈。** 读谱题检查时值与拍号关系，听辨题检查声音判断，再现任务检查节奏表现。三类结果分别记录，不因其中一项完成便宣布全部目标达成。

**当前限制。** 未制作、播放音频，也未验证节奏表现。该例只用于检查技能是否能识别媒体和评价差异。

## S：用数据解释一个生物现象

**品类与目标。** 自然科学 / 数据解释。具体题材在获得可靠材料后确定，目标是区分数据中的模式与对模式的解释。

**编排。** 提出可研究问题 → 阅读有来源和单位的数据 → 描述模式 → 比较可能解释 → 指出还缺什么观察 → 写出有限结论。

**反馈。** 要求读者说明哪条数据支持哪项判断、还有哪些替代解释。构造的教学数据必须明示，不能把“看起来合理”的数字写成已做实验。尚未选定数据，因此本例仍停留在结构阶段。

## H：比较两份事件记录

**品类与目标。** 人文 / 材料解释。目标是辨认两份记录的一致、分歧和各自不能回答的问题，并给出有材料支持的判断。

**编排。** 提供出处和必要背景 → 分别辨认陈述、作者与目的 → 对照证据 → 形成解释 → 写出不确定部分及进一步查证方向。

**反馈。** 同时给出事实约束、证据使用要求和多种可成立的论证路径。若用虚构材料练方法，明确其教学用途，不编造真实档案出处。本例尚未选取史料，不交付假装已核查的历史结论。

## 如何使用这些试稿

下一步不是把八个提纲扩写成同样长度，而是先选择一个单元做完整材料分析和交付，再用其他单元检验分类、任务和媒介规则。每次试用都记录：哪些材料被采用或舍弃、为什么这样选品类、哪个活动真正检验目标，以及仍缺哪些证据。
