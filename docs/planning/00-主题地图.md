# 中文讲解教材研究主题地图

目标是形成可组合的教材编写 skill 集合，从编程与计算机逐渐扩展到工程、数学、外语、艺术及其他主题。当前采用“共用任务入口 + 按品类选择的方法资料”的设计，先收集材料，再分析并选定具体品类，最后编排教程。

讲解语言固定为中文，学习对象、术语等必要原文按[讲解语言与范围](01-技能集合设计.md#讲解语言与范围)处理。研究外文教材不意味着增加多语种出版任务。

## 品类覆盖地图

| 品类 | 当前代表案例 | 优先拆出的子类型 | 当前深度与下一步 |
|---|---|---|---|
| 编程与计算机 | CS:APP、OSTEP、SICP、HtDP、Nand to Tetris、D2L 等 | 概念与机制、编程方法、算法证明、项目与实验 | 已有两轮笔记；需原创单元与代码验证 |
| 工程 | Engineering Statics；电路教材与 MIT 6.002 | 模型分析、实验测量、约束下设计 | 已有案例与配套分析；需实际图例和实验记录样本 |
| 数学 | Book of Proof；Active Calculus | 概念、计算、证明、探究、建模 | 已查看证明书样页；统计与建模仍需专门案例 |
| 外语 | 《いろどり》；English Grammar in Use | 交际、听读、语音、写作、语言知识查补 | 已比较目标与用法；需试听及中文讲解样例 |
| 视觉艺术与设计 | Interaction of Color | 感知、制作、作品分析、设计 | 目前主要是公开介绍；需可合法细读的完整教学单元 |
| 音乐 | Open Music Theory 2 | 乐理、作品分析、听觉训练、表演 | 已有官方说明和书评；未试听，表演类仍缺案例 |
| 自然科学 | Biology 2e | 概念模型、观察、实验、数据解释 | 扩展探针；需具体探究活动和反例材料 |
| 人文 | World History Volume 1 | 材料解读、论证、比较解释 | 已读材料分析单元；需其他人文领域样本 |
| 其他主题 | 待具体项目选样 | 按学习产出重新确定 | 不标记为已支持，不机械沿用现有模板 |

当前案例和取证范围见[跨品类研究概览](../research/2026-11-18/00-跨品类研究概览.md)。一个品类可以采用多种教学结构，一种结构也可以服务多个品类。

## 共用研究主题

| 主题 | 要解决的问题 | 目标成果 |
|---|---|---|
| 材料收集 | 区分内容依据、教材写法案例、可用教学资产 | 带版本、位置、用途与限制的材料清单 |
| 材料分析 | 哪些目标有依据，哪些存在缺口或冲突 | 内容与目标对应、取舍和待补项 |
| 品类选择 | 学什么、做什么、用什么证据判断学会 | 主品类、子类型、辅助品类与选择理由 |
| 读者与条件 | 先修、用途、自学或课堂、设备与反馈 | 任务书、必要的先修诊断 |
| 内容组织 | 依赖、问题、任务、项目或查阅如何组织 | 有目标、依赖和练习位置的目录 |
| 解释与示例 | 如何显露前提、过程、误解和限制 | 章节模式、对照例、过程说明 |
| 活动与反馈 | 什么任务能验证目标，如何支持受阻读者 | 练习、提示、答案或评价依据 |
| 中文与术语 | 如何讲清楚，同时保留必要原文和符号 | 术语、符号、引文及图注约定 |
| 媒体与排版 | 哪些信息必须通过图、声音或操作呈现 | 媒体清单、图解说明、样张与输出记录 |
| 专业审校 | 本品类怎样核对内容，结论能支持到哪里 | 问题、证据、影响与未验证项 |
| 试读与试教 | 读者实际如何理解、操作和迁移 | 观察任务、真实记录、修订理由 |
| 维护与交接 | 修改后哪些正文、答案、媒体需要重验 | 变更影响与重验记录 |

## 研究优先级

第一优先级是分类与编排：用同一批材料面对不同目标，检查是否选出不同教学任务；用不同材料面对相同目标，检查是否仍能保持必要的学习结构。具体流程见[材料分析与品类选择](03-材料分析与品类选择.md)。

第二优先级是每类至少一个完整小单元，重点验证该类独有的失败方式。数量是项目的覆盖目标，不是教材内容的固定配额。首个编程单元继续保留，数学、工程、外语和艺术单元逐步加入。

第三优先级是实际媒介与读者使用。先做目标载体的真实样张或活动，再决定工具和自动化脚本；不提前为所有学科安排同一种出版平台。

## 后续选样方式

继续保留教师评价、课程采用和具名推荐，但分别记录来源、版本和评价内容。既收集优点，也收集具体批评。进一步比较同一任务的不同教法，避免只摘每本书最亮眼的特点。

中文原创教材和面向中文读者的实际试用仍明显不足。下一轮应补充它们，重点观察讲解习惯、术语、读者基础和版式，而非把外文教材逐句译成规则。艺术、外语的素材访问与版权条件另行记录；公开可读不等于允许把素材并入成果。
