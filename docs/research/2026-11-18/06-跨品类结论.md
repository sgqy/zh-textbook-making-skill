# 跨品类综合：共用工作方法，分别选择教学结构

以下是基于本轮案例提出的设计结论，不是跨学科学习效果实验的结果。具体观察和来源见[研究概览](00-跨品类研究概览.md)及各品类笔记。

## 可以共用的工作方法

先确定读者和需要完成的任务，再分析材料中的内容、先修关系、例子、活动和证据。给重要结论标记来源与适用条件，使正文、图像、练习、答案和媒体保持对应。最后分别检查专业正确性、教学匹配和实际呈现。

这些方法可以共用，因为它们描述编写者要做的工作；章节内部的学习活动仍须按品类选择。

## 不能直接统一的六项选择

| 选择 | 案例揭示的区别 | 本项目的候选规则 |
|---|---|---|
| 章节顺序 | 证明书需要依赖主干；语法查补书可按困难检索 | 分清线性学习路径与查阅入口；允许同时存在 |
| 示例与探索 | 完整示范、课堂探究和工作室实验提供的支持不同 | 根据先修与反馈条件决定支持程度，不固定比例 |
| “正确”的含义 | 程序运行、证明成立、测量可信、交流成功、作品合意各不相同 | 在出题前写出本单元的可接受证据 |
| 答案与反馈 | 数值解、证明、多种表达、设计方案的答案形态不同 | 分开确定答案、必要条件、合理多解和评价依据 |
| 媒体功能 | 有的图辅助说明，有的色彩、声音就是学习对象 | 标注媒体是否为完成目标所必需；转换格式时检查目标损失 |
| 学习支持 | 自学、课堂、实验室、工作室可获得的反馈不同 | 把教师、伙伴、设备和反馈条件作为编排依据 |

## 品类对排版的具体影响

下表是待试样验证的要求。它没有预先规定字号、行数和版心尺寸；这些要用实际目标载体检查。

| 内容 | 读者需要同时或先后看到什么 | 排版检查 |
|---|---|---|
| 编程 | 代码、输入、输出、状态说明 | 换行和缩进是否保留含义；复制内容是否可用 |
| 工程 | 对象图、坐标、尺寸、公式、单位 | 图文标记一致；标注可读；图示与实物有无混淆 |
| 数学 | 命题条件、推理、符号解释 | 条件不脱离结论；推导断行可追踪；证明结束清楚 |
| 外语 | 原文或音频、任务、解释、核对材料 | 转写和答案出现时机合适；原文标记清晰；音频可定位 |
| 视觉艺术 | 对照图、局部细节、制作过程 | 对照条件可比较；尺寸与色彩是否影响任务 |
| 音乐 | 乐谱、声音、分析标签、小节位置 | 谱例可读；播放对象正确；纸面访问配套资源的路径明确 |
| 自然科学 | 数据图、图例、尺度、模型 | 示意和测量图有区分；坐标单位和数据身份清楚 |
| 人文 | 原材料、出处、解释和问题 | 引文与编写者解释可区分；节选和语境可定位 |

实际样页为这些判断提供了局部依据：Book of Proof 印刷页 x、118，以及《いろどり》入门使用说明第 5 页。艺术媒体效果、工程图和手机端仍未实测；不得把表中的要求写成已验证结果。

## 对旧草稿的修正

1. “技术审校”扩展为按品类进行专业审校；代码执行只是其中一种证据。
2. “例题—练习”保留为可选结构，增加探究、实验、交际、创作与材料解释结构。
3. “每章有答案”改为每项练习有合适的反馈：可能是解答，也可能是判断条件、评价维度和修改建议。
4. “静态替代”要说明保留哪些目标；音频、交互、色彩不一定能无损转换。
5. “中文讲解”不限制目标语言练习，也不要求把代码、乐谱和数学符号改写为中文文字。
6. “覆盖更多主题”用新增案例和试稿证明，不用不断增加目录标签证明。

## 如何防止案例研究变成模板拼接

研究记录先回答该书为谁解决什么学习困难，再观察其结构如何服务目标。提炼规则时补上适用条件和反例。例如“解释与练习靠近”适合立即应用，但测评答案可能需要延后；“图形直观”可能帮助形成猜想，但不能替代证明；“开放创作”允许多解，但仍要明确限制与评价依据。

本轮尚缺相同任务的多书正文比较。下一步可分别比较证明入门、请求澄清、受力图或色彩对照任务的两种教法，记录先修假设、活动顺序、反馈和媒体条件。只有来源介绍而未读到正文时，应明确标记，不把宣传性主张转化为强制规则。
