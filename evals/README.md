# 行为评估

这些任务用于观察技能在真实请求中的选择。自动文件检查不能代替行为评估；把案例放进目录也不表示已经执行。

## 执行方式

选与本次修改相关的案例。在隔离临时项目中安装或复制需要的技能，只向执行者提供该案例、技能和完成任务所需的原始材料。需要独立评估时，不提供评价依据、预期答案或本轮修正思路。

用现有 AI 工具执行任务，无需为本仓库配置特定模型 API。实际写出的文件保留到结果目录或作为记录附件；不要只保存一句“通过”。产生外部操作的案例按实际任务授权执行，当前案例不要求发布或发送消息。

执行后由评估者参考[评价依据](rubric.md)，记录实际输入、技能版本、工具与环境、输出、观察到的问题和限制。独立评估与编写者自测分别标明。
