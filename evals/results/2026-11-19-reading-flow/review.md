# 案例 09 审校记录

本次在同一会话中使用复制包的 textbook-review 审阅原稿与改稿，检查范围是正文连续性、数学条件、解释、练习反馈和材料身份。没有独立执行者，没有真实读者观察，也没有渲染成品。

## 原稿中的确认问题

| 位置 | 问题与影响 | 建议 |
|---|---|---|
| 从两项分数转入术语段 | 翻译和索引字段没有帮助解释份数，打断从普通平均到权重的过渡 | 删除编辑流程细节；检索词可放术语表 |
| 公式及“请先跳到附录 A” | 权重条件与分母解释被移走，读者要往返才能理解公式 | 将非负、总和大于 0 及总份数解释就地讲清 |
| 公式与代入之间 | 完整编制说明和调查方法提示中断计算 | 就近标明构造数据身份；以简短出处保留来源，编制细节留在材料档案 |
| 70 分与 75 分比较之后 | 其他平均数的分类未服务当前比较，另起了需要系统展开的任务 | 留给后续专节；本节解释权重变化与结果的关系 |

## 改稿复核

正文按普通平均、份数示例、合并计算、公式条件和结果比较推进。计算 (120 + 90) / 3 = 70 与 (60 + 180) / 3 = 80 成立；公式前给出非负权重及总和大于 0 的条件，零权重情形没有被误写为均值 0。

读者可以略过唯一的出处脚注，仍完成当前计算和判断。练习保留先预测、再计算与说明理由的任务，反馈随后给出。材料 S1 始终标为构造数据，没有虚构出版物、实验或读者结果。
