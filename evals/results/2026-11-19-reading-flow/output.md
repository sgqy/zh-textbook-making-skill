# 用份数理解加权平均

普通平均数让每项分数占同样份量。例如，60 分和 90 分的平均数是 (60 + 90) / 2 = 75 分。如果第一项占两份，第二项占一份，就要把各项所占的份数也算进去。以下分数是为练习构造的数据。[^S1]

这里把每项所占的份数称为权重。权重为 2 和 1，可以看成把 60、60、90 三份分数求平均：

(60 + 60 + 90) / 3 = 70 分。

分子是所有份数对应的分数之和，分母是总份数。把相同的分数合并，就得到 (2 × 60 + 1 × 90) / (2 + 1)。按各项权重求得的平均数，称为加权平均数。

对于两项分数 x₁、x₂，设它们的权重分别为 w₁、w₂。按本节的份数含义，权重必须非负，而且总和大于 0。加权平均数 m 的公式为：

m = (w₁x₁ + w₂x₂) / (w₁ + w₂)。

例子中的总权重是 3，符合条件。普通平均数为 75 分，加权平均数为 70 分，是因为较低的 60 分占了更多份。如果两项权重都是 0，就没有可用于平均的份数，分母也为 0，不能使用这个公式。

## 试一试

保持分数为 60 分和 90 分，把权重改为 1 和 2。先判断结果会比 75 分大还是小，再计算。如果两项权重都改为 0，结果能否写成 0 分？说明理由后再看反馈。

## 核对与反馈

90 分现在占更多份，结果应大于 75 分。计算得到 (1 × 60 + 2 × 90) / (1 + 2) = 80 分。两项权重均为 0 时，无法按此公式求平均，不能把不可计算写成 0 分。
