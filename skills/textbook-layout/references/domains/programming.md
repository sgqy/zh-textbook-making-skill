# 编程与计算机

先区分概念机制、编程方法、算法证明和项目实践。固定与内容有关的语言、运行环境和版本；不为展示覆盖面提供多语言实现。

## 组织与反馈

机制型内容可从现象和预测进入模型、执行轨迹，再改变条件。方法型内容显示关键选择和调试过程。项目型内容说明每阶段的输入、输出、依赖及可观察状态；允许读者从已有阶段继续。

示例代码、输入、输出和图必须描述同一次执行。练习可使用预测、补全、修改、诊断和独立实现，选择与当前目标对应的任务。提示逐步提供关键线索，答案解释错因，避免只给完整源码。

算法区分方案、正确性和成本。说明假设、终止、边界条件以及复杂度度量；程序测试不能代替一般性证明。引用语义、并发和数值行为按实际语言与环境检查，不将示意图当真实运行记录。

## 专业与呈现检查

在可用的指定环境运行必要示例，核对边界输入和正文输出。无法执行时明确静态审查范围。并发模拟、真实并发运行和证明分别标注。

代码换行、缩进、字符与复制结果保持可用；行号不进入复制内容。图中名称与代码对应。长清单可按教学任务拆分，并提供完整版本位置。
